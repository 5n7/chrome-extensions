# Context Map

## Contexts

- [Recent Tab Switch](./extensions/recent-tab-switch/CONTEXT.md) — Ctrl+Tab in most-recently-used order
- [Twitch Seek Keys](./extensions/twitch-seek-keys/CONTEXT.md) — custom keyboard seek amounts on twitch.tv
- [Twitch Spoiler Guard](./extensions/twitch-spoiler-guard/CONTEXT.md) — hides remaining-time cues on Twitch VODs
- [YouTube Auto Speed](./extensions/youtube-auto-speed/CONTEXT.md) — plays YouTube videos at rule-chosen speeds

## Relationships

Each extension is an independent context. Twitch Seek Keys and YouTube Auto Speed define a Key Combination the same way, but neither depends on the other.
